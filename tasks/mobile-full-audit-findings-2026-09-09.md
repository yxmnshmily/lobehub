## 已定位，待后续批次修复

### P1：功能或主信息可用性

- [ ] 管理员权限首次加载会替换整个主壳，导航和内容同时闪变。
- [ ] Electron 分屏/多标签的侧栏 registry 只按 `navKey` 存储，相同页类型可相互覆盖。
- [ ] 中等窄度下 `workspace-settings` / `project` / `resourceLibrary` / `agent-docs` / `eval` 仍保持至少 240px 侧栏，持续挤压主内容。
- [ ] 受邀群的部分子路由仍通过 pathname 手工分发，与 owner 的 `<Outlet />` 链路不一致。
- [ ] 群侧栏外层和成员/话题内层共存多层滚动，在矮屏可造成滚轮陷阱。
- [ ] 资源列表/Masonry 的主点击面仍是普通 `div`，缺少键盘打开语义。
- [ ] 聊天输入框对普通 Tab 的行为与页面焦点导航冲突，需在“编辑缩进”和“可离开输入区”之间明确产品取舍。
- [ ] 超长 AI 回复始终整段渲染，没有与用户长消息一致的折叠/详情策略。

### P2：响应式、密度与反馈

- [ ] Workspace `navKey` 依赖异步的 active slug，首帧可先出现 Home 侧栏再切回 Workspace。
- [ ] 开启促销 Banner 时 Web/Electron 主容器的高度扣减分支不一致，底部存在裁切风险。
- [ ] 未知 `/settings/:tab` 会静默渲染 Appearance，地址、侧栏和内容可互相矛盾。
- [ ] 群成员/话题新页面存在整页硬编码中文，非中文 locale 会混用语言。
- [ ] 输入历史弹层缺少 `listbox/option` 语义与当前项宣告。
- [ ] `/me/profile` 和 `/me/settings` 的返回按钮尚未统一到 44px 手机页头 token。
- [ ] 头像编辑提示仅 hover 可见，触屏可发现性不足。
- [ ] 资源上传超尺寸图片与部分上传失败仍缺少就地错误提示。
- [ ] 资源搜索清空按钮的图标热区与无障碍名称仍需统一。
- [ ] 图片/视频引用缩略图堆叠操作仍存在 hover 依赖和小热区。

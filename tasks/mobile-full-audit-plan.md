# LobeHub 手机端全量排查与修复计划

## 目标

在真实手机视口下，覆盖 LobeHub 可到达页面和可见交互控件，修复导航错误、按钮失效、内容溢出、错位、挤压、遮挡、主题不可见和安全区问题。

## 验收范围

- 视口：390×844 为主，360×800 为窄屏补充。
- 主题：浅色、深色。
- 页面：移动端路由及页面内可达的抽屉、弹窗、菜单、设置子页。
- 控件：按钮、链接、菜单项、标签页、开关、输入框、关闭/返回操作。
- 证据：页面截图、控制台错误、失败请求、路由结果、布局测量和聚焦测试。

## 验收标准

- 可见控件点击后行为确定，内部导航不会误跳个人页、首页或登录页。
- 页面无非预期横向溢出；文字和按钮无裁切、重叠、挤出容器。
- 固定头尾、弹窗、抽屉和菜单不被安全区或浏览器工具栏遮挡。
- 主要触控目标不小于 44×44；确需紧凑的文本链接保持足够间距。
- 浅色、深色主题下，图标、关闭按钮、文字和边界均清晰可见。
- 每项修复先有可复现失败，再做最小修改并重新验收。

## 执行阶段

1. 建立移动路由、页面和交互控件清单；准备隔离的本地测试登录态。
2. 跑首轮真实移动视口检查，记录 P0（无法使用）、P1（明显错位/遮挡）、P2（体验瑕疵）。
3. 按“导航与按钮 → 布局与溢出 → 弹窗/抽屉/安全区 → 深浅主题”分批修复。
4. 重跑受影响页面和全量移动矩阵；对未能自动验收的外部登录能力单独列出阻塞。

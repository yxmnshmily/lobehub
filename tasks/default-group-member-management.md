# 默认超级工作群成员管理：当前用户确认规则

本文件记录本次用户确认，覆盖此前固定四成员、仅后台编辑的交互要求。

- 普通用户与管理员共用群页面结构；仅管理员拥有全平台成员配置写权限。
- 管理入口位于群内成员面板，提供添加、编辑、移除。移除前明确提示会同步所有用户默认群。
- 已有成员配置是来源：保留可发布的模型、工具、技能和核心指令，不用临时生成的模板替代。
- 编辑原配置后需要明确发布同步；未发布的个人编辑不能静默影响其他用户。
- 移除只解除默认群中的成员关系，不删除源成员档案或历史消息。初始化不得把已移除成员重新补回。
- API 密钥、私人 OAuth 授权、本地设备绑定、私人知识库/文件不随配置跨用户复制。
- UI 统一称“成员”，技术字段名和用户自定义名称不做批量重命名。
- 保留一个有效的群主统筹；更换统筹必须是明确的替换操作，不能直接让默认群失去统筹。

实际发布名单需要使用已核对的源成员 ID。截图里的显示名不能当数据库唯一标识；不按同名猜测或复制私人凭据。

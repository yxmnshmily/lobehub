# 群页面权限恢复核查

本轮核查：2026-09-08。依据当前工作区差异及对应入口、原有资源权限和数据库调用链；不把工作区内其他任务的所有改动都归为本次新增，也不声称已经逐页人工验收全站。

## 已恢复的额外限制

| 入口/功能                | 原问题                                                   | 当前处理                                                                      |
| ------------------------ | -------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 群话题页面               | 复用的数据源被统一视为只读，缺少勾选、批量管理和归档入口 | 群主的数据源接回原有管理组件；收藏、归档/恢复、删除、移动入口可用             |
| 话题删除、批量清理、移动 | 默认超级群话题被永久保留过滤器排除                       | 撤销 TopicModel 的额外过滤与归属字段锁定，保留原有 ownership 校验             |
| 消息删除/清空            | 四个删除接口对默认超级群额外抛出永久保留错误             | 删除该 guard 和不再使用的实现、旧测试；原有 message:delete 和资源目标校验保留 |
| 群组删除                 | 默认群被单独禁止删除和批量删除                           | ChatGroupModel 恢复原有逻辑，仍只操作有权限的数据                             |
| 删除并重新生成           | 默认群跳过删除，永远留下旧回复                           | 恢复原有先删除、再生成流程；保留托管执行与计费入口                            |
| AI 成员预览              | 成员页、侧栏、群信息面板以“不是群主”额外强制只读         | 三个入口均撤掉该覆盖判断，由原有账号和资源编辑权限决定                        |
| 退出群提示               | 文案宣称“自己的超级群仍永久保留”                         | 改为“自己的超级群不受影响”，不再承诺永久保留                                  |

## 2026-09-07 账户余额与全量类型修复

- 余额：验证接口字段、修正缺字段提示，获准后重启本地旧接口并实际验收。
- 售价：默认 10 元/100 万积分；下单与支付配置共用，历史订单和 API 扣费单位不变。
- 类型：后端、前端按互不重叠文件分工；主代理负责共享包、认证与账户。禁止关闭检查或宽泛断言掩盖错误。
- 验收：相关测试、全量 tsgo、聚焦审查；不部署线上，不操作真实账款。

1. 以官网 `site-shell.js` 为唯一导航实现，LobeHub 组件只建立共享脚本挂载点。
2. 让统一开发网关始终把 `/assets/*` 交给官网资源服务器，避免 LobeHub 路由吞掉共享资源。
3. 将同一外壳挂载到五个 Web 入口，不改路由表和业务页。
4. 运行共享资源路由测试和聚焦检查，再用同一浏览器批次验收桌面/手机、分享和明暗主题。

风险：现有页面多为 `height: 100%` 应用外壳。共享官网头部保持固定定位，LobeHub 内容统一留出 72/80px 顶部空间；导航模式不生成官网页脚和页面滚动条，避免破坏应用内部布局。

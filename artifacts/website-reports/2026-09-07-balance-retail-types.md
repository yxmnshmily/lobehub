# 余额、积分售价与全量类型修复

## 实际修改

- 充值默认售价：1000 分人民币购买 100 万积分，默认支付配置与创建订单共用售价常量；已有显式商户价格覆盖保留。历史订单金额不重算，API 成本的美元计量不变。
- 余额：旧接口对象存在但缺少 `availableCredits` 时，账户用量和积分余额页面不再漏掉读取异常入口。禁止将 `balanceCredits` 当作可用积分；冻结积分由服务端计算。
- 类型：异常抛出函数显式 `never` 签名、前后端公开数据投影、React/UI 组件 API、测试夹具、认证 SDK 窄接口、数据库 usage JSON 的 `ModelUsage`（含汇率快照）、群成员只读类型等；未修改 tsconfig 或关闭类型检查。

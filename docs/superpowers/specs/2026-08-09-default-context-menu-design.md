# 新账号默认启用右键菜单

## 目标

将网页端未保存 `contextMenuMode` 的用户默认行为从 `disabled` 改为 `default`。

## 行为边界

- 新账号未保存该设置时，启用右键菜单。
- 老账号未保存该设置时，跟随新默认值并启用右键菜单。
- 已明确保存 `disabled` 的账号继续禁用右键菜单。
- 已明确保存 `default` 的账号保持启用。

## 实现方案

修改用户通用设置选择器的缺省回退值，使 Web 与 Desktop 在 `contextMenuMode` 未定义时均返回 `default`。不增加账号创建写库逻辑，不迁移或覆盖任何已保存的用户设置。

## 验证

- 增加选择器测试，证明未保存设置时返回 `default`。
- 增加选择器测试，证明显式保存的 `disabled` 优先于默认值。
- 运行该选择器的聚焦测试，并检查最终差异不包含其他任务的文件。
